# Yolk screenshots

Drop screenshots of the Yolk prototype into this folder and they appear as a
"Screenshots" strip at the bottom of the case study on the next build. Nothing
else is needed: `src/_data/work.js` lists this folder at build time.

1. Export the screens from the Adobe XD file (or take phone screenshots) as
   JPEG, PNG or WebP, no wider than 2500 px on the long edge and under 25 MiB.
2. Upload them here (GitHub: **Add file → Upload files**). Use plain names such
   as `01-home.png`, `02-set-mood.png`; the number keeps them in order.
3. Optional: add a `.txt` file with the same name (`01-home.txt`) holding the
   alt text, one or two literal sentences describing the screen. Without it the
   filename is used ("01 Home").

The strip only renders when at least one image is here, so this README on its
own changes nothing.
